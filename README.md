# 🌐 Personal Portfolio Site

A clean and responsive personal portfolio website showcasing my skills, projects, and contact information — built using HTML, CSS, and JavaScript, and deployed via GitHub Pages.

---

## 🎯 Overview

This project represents my web development profile. It is designed to be simple, elegant, and easy to navigate, helping visitors learn more about me, my work, and how to reach me.

---

## ✨ Features

- 🖥️ Responsive layout for desktop and mobile
- 🎨 Stylish design with custom CSS
- 📷 Image and social media sections
- 🧭 Smooth navigation with internal anchors
- ⚡ Hosted via GitHub Pages

---

## 🛠️ Tech Stack

| Technology | Purpose              |
|------------|----------------------|
| HTML       | Page structure       |
| CSS        | Styling and layout   |
| JavaScript | Interaction and logic|
